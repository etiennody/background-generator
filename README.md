# Background Generator

Small web app that lets you pick two colors and generates a linear-gradient background while displaying the CSS for it, with a one-click black mode for readability.

## Getting started

Open `index.html` in your browser.

## Development

Build the browser bundle and run the dev server:

```bash
npm run build
```

## Tests

Install dependencies and run the test suite:

```bash
npm install
npm test
```

Tests use Jest + JSDOM to exercise the gradient update logic.
